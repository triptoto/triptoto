# tripto.to Mobile Design Lock v1

This package removes visual ambiguity from implementation.

It contains:

- the approved reference images;
- locked design tokens and typography;
- exact screen measurements at 390 × 844;
- a runnable Home + Flight Detail reference implementation;
- one copyable Codex integration task.

## Preview

```bash
cd src
python3 -m http.server 8080
```

Open:

- `http://localhost:8080/#home`
- `http://localhost:8080/#flight`

## Typography

The package uses the Apple system font stack. It does not include or distribute font files. On Apple devices, Safari/Chrome automatically use the installed SF family.
