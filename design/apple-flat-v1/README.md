# tripto.to Apple Flat UI v1

This directory preserves the single approved visual source for the production UI.

- Apple system typography
- Pure white canvas with cool-concrete card surfaces
- Jet-black primary text and actions, asphalt secondary text, and silver borders/icons
- Flat chronological timeline instead of dashboard cards
- Local Phosphor icon font; no external font or icon requests
- One touch date-range calendar for trip and hotel ranges

The superseded Product V2 prototype package and the earlier mobile design-lock package were removed after the production implementation replaced them.
