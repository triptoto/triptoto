# tripto.to welcome concepts

Twelve independent, review-only welcome pages. They do not replace or modify the production application. Concepts 11 and 12 are the denser alternatives with substantially less unused space.

## Open

Serve this directory and open `index.html` for the gallery. Each concept also has its own `concept-01.html` through `concept-12.html` URL.

## Visual rules

- No images, photos, SVG assets, icon packages, external fonts, or background images.
- Production palette only: `#111217`, `#CB2957`, `#EEEEEE`, `#FFFFFF`, `#E4E4E4`, `#5A5A5A`, `#FBE7EC`.
- Apple system font stack.
- One-screen mobile layout with no page scrolling.
- Responsive for 360×800, 375×812, 390×844, 393×852, and 430×932.
- 44px minimum interactive targets, keyboard focus, semantic dialog, and reduced-motion support.

## Pixel control

Shared measurements and colors are tokens at the top of `styles.css`. Each option has a dedicated `.concept-N` section, so the selected direction can be adjusted precisely without affecting the other eleven.

The Google button is a design preview. Production integration must continue to use Google's approved branding and secure sign-in implementation.
