## Evidence cautions

- Earlier/related links are reproduction context, not always a frozen screenshot before that individual patch. The dedicated `before/` series captures the original 60 routes. Shared interaction fixes were made during discovery.
- `attachments/keyboard-before.json` records the actual viewer failure. `final/document-return.json` records ten passing checks: semantics, initial focus, Tab containment, Escape, history state, focus return, unchanged form values, Back behavior, restored background and staged-file removal.
- DA-18 has an executable input-handler regression in `tests/currency.contract.mjs`: null, undefined and NaN must not become a zero result. The large positive rate in screenshots is explicitly a LOCAL QA fixture, not travel or financial data.
- `completion/regression/results-edit.json` verifies that all 18 edit forms really have their More Details panel open. Earlier `final/edit-*` images show the collapsed state because prefilled panels were already open and the first test toggled them closed.
- No unresolved failure from an earlier attempt was turned into a pass by counting a later unrelated screenshot. Superseding evidence and platform gaps are listed in [methodology](methodology.md).

## Validation

Post-audit user change: removed the entire Timeline “Before you go” preparation card, its countdown/actions and dedicated styles. Rebuilt the shell; syntax, mobile UI contract and diff checks passed. Browser checks at 320/390/430px confirmed that the card is absent, the timeline remains visible and navigation remains at the bottom. This is a requested removal, not an additional audit defect. Earlier baseline captures intentionally retain the old card. No deployment was performed.

- `npm run validate:v2` passed after the JavaScript changes, including local D1 integration, authentication/roles/sharing contracts, collections, loading and viewport contracts.
- The final two changes were CSS only: narrow stop-form selector specificity and 24px long currency output. After them, the shell was rebuilt, `npm run check:ui` passed, and the phone responsive regressions were repeated.
- Existing contracts were updated to the approved card hierarchy and app-owned confirmation implementation. These source contracts supplement, rather than replace, rendered browser evidence.
- Remaining platform/integration checks: actual Google flow, real deletion preview/recognition endpoints, physical iPhone keyboard, actual browser zoom 200% and PDF-plugin internals. See [coverage](coverage.md).
